#MovieFlix

MovieFlix is a scalable and responsive movie streaming application built using **Spring Boot**, **Java**, **MySQL**, and **HTML/CSS/JavaScript**. It allows users to browse, search, and stream movies, with separate interfaces for admins and regular users.

---

##Features

###User
- Sign up / Sign in with secure authentication
- View movie details (rating, genre, description)

### Admin
- Admin dashboard
- Add, update, and delete movies
- Manage users and categories
